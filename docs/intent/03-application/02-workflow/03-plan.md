# Plan

Plan gives the AI room to understand the Goal and decide how to approach it before implementation. The Goal may come from a user or another AI. Refine does not require a user-specified outcome, an acceptance checklist, or a prescribed planning method.

After Todo admission, Refine pins the current Goal, Round, step, node, and Git base and runs the selected Plan Skills. Their instructions guide the AI's judgment. The agents report success, failure, or an execution error; useful planning detail is optional. Multiple reports remain separate in Skill history and are supplied to implementation as context. There is no additional planning phase machine or checklist coverage rule.

Plan may edit the repository or request a supported workflow change when its Skill instructions and current user authorization call for it. Refine checks response identity and current workflow authority, retains results and process records, and follows the reported decision. Failed or interrupted work is not automatically repeated. Another attempt requires an explicit workflow decision.

Historical structured plans, criticism, revisions, and implementation reports remain readable. They provide context without independently authorizing or blocking current work. An explicit recovery Round retains the earlier work and follows the configured workflow.
