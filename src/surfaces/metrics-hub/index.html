Definitions and data coverage
  • Windows are rolling: 24 hours, 7 days, 30 days, 90 days, or 365 days. Dates and chart buckets use UTC. Comparisons use the immediately preceding equal-length window.
  • Rounds per Goal counts all retained rounds on Goals created in the selected window, including unfinished Goals. Deleted Goals and deleted rounds are absent.
  • Delivered means currently Done with a final-Round integration timestamp in the window. Manually completed Goals without that evidence are counted in current status, but excluded from delivery trends and time calculations.
  • Delivery time measures creation to recorded integration, including waiting. It is not agent execution time. Missing or invalid timestamps are excluded.
  • Current status and round counts describe the saved snapshot, not a historical reconstruction. Reporter and node assignments can change. Node activity is not compute utilization.
  • Data covers this target app's retained, synced Goal records. Refresh reads Goals individually while other work may continue. Updates on other nodes appear after state synchronization.
