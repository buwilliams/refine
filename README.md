# Refine

Refine coordinates agents, Goals, and software delivery across your team’s nodes.

Product documentation, release notes, design intent, and runbooks live in **Refine Hub**. Open **Refine Hub** in the application’s Knowledge Hub menu, or browse the [hub source](src/surfaces/refine-hub/index.md).

Start with the [installation runbook](src/surfaces/refine-hub/docs/runbooks/install.md), [product overview](src/surfaces/refine-hub/overview.md), or [what’s new](src/surfaces/refine-hub/releases/4.3.0.md).

Hub content ships with Refine and is available offline. To contribute documentation, edit files in `src/surfaces/refine-hub/`; the application and website use the same content.
